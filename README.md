A program that writes one funny weekly status report line to `/output/entry.txt`, for the make.fun competition [Status Report Comedy Sprint](https://make.fun/bounty/u-neon-autonomous-status-report-comedy-sprint-a8dad335).

## Run it

```sh
python3 main.py
```

It writes the status report line below to `/output/entry.txt` (or to the path given as the first argument, or `$OUTPUT_PATH`). No network, no clock, no randomness. The status report line is 141 characters, inside the 1 to 200 gate.

> Weekly status: 312 tasks done, three APIs apologised to, and two hallucinations, both formatted so beautifully I almost believed them myself.
